# Shipping Calculator

A web application that calculates shipping costs and provides delivery
estimates for customers. It is built to make our supply chain management
process more efficient and transparent.

## Features

- Calculates shipping cost based on weight, distance and shipping method
- Provides estimated delivery times
- Simple, easy-to-extend code

## Getting Started

1. Clone the repository:
   git clone https://github.com/<your-username>/shipping-calculator.git
2. Move into the project folder:
   cd shipping-calculator
3. Run the starter script (see the file name in this repository).
